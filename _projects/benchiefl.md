Open Information Extraction (OIE) is a field of NLP that aims to present textual information in a format that allows it to be organized, analyzed and reflected upon. Numerous OIE systems are developed, claiming ever-increasing performance, which calls for objective benchmarks. To our knowledge, the latest reference benchmark was [BenchIE](https://aclanthology.org/N22-1009/).

Despite being very well thought out, we noticed a number of issues we believe are limiting. We therefore propose **BenchIE^FL**, a new OIE benchmark which fully enforces the principles of BenchIE while containing fewer errors, omissions and shortcomings when candidate facts are matched towards reference ones. It was built through a **manual re-annotation process** of the reference data. BenchIE^FL allows insightful conclusions to be drawn on the **actual performance of OIE extractors**.

This work is an extension of my M.Sc. thesis, *Méthodes d'évaluation en extraction d'information ouverte* (Université de Montréal, 2023).

**Authors**: Fabrice Lamarche, Philippe Langlais

**Published at**: Findings of the Association for Computational Linguistics: ACL 2024
